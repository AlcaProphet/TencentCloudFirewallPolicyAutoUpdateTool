## 1. 接口描述

接口请求域名： vpc.tencentcloudapi.com 。

本接口（ModifySecurityGroupAttribute）用于修改安全组（SecurityGroupPolicy）属性。

默认接口请求频率限制：50次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/215/15758)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/215/15758)，本接口取值：ModifySecurityGroupAttribute。 |
| Version | 是 | String | [公共参数](/document/api/215/15758)，本接口取值：2017-03-12。 |
| Region | 是 | String | [公共参数](/document/api/215/15758)，详见产品支持的 [地域列表](/document/api/215/15758#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| SecurityGroupId | 是 | String | 安全组实例ID，例如sg-33ocnj9n，可通过<a href="https://cloud.tencent.com/document/product/215/15808">DescribeSecurityGroups</a>获取。<br/>示例值：sg-33ocnj9n |
| GroupName | 否 | String | 安全组名称，可任意命名，但不得超过60个字符。<br/>示例值：demo |
| GroupDescription | 否 | String | 安全组备注，最多100个字符。<br/>示例值：demo |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 修改安全组属性

修改安全组属性

#### 输入示例

```
https://vpc.tencentcloudapi.com/?Action=ModifySecurityGroupAttribute
&SecurityGroupId=sg-33ocnj9n
&GroupName=demo
&GroupDescription=demo
&<公共请求参数>
```

#### 输出示例

```json
{
    "Response": {
        "RequestId": "354f4ac3-8546-4516-8c8a-69e3ab73aa8a"
    }
}
```
