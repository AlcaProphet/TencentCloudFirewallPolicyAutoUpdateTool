## 1. 接口描述

接口请求域名： vpc.tencentcloudapi.com 。

本接口（CloneSecurityGroup）用于根据存量的安全组，克隆创建出同样规则配置的安全组。默认仅克隆安全组及其规则信息，可通过入参开启克隆安全组标签信息。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/215/15758)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/215/15758)，本接口取值：CloneSecurityGroup。 |
| Version | 是 | String | [公共参数](/document/api/215/15758)，本接口取值：2017-03-12。 |
| Region | 是 | String | [公共参数](/document/api/215/15758)，详见产品支持的 [地域列表](/document/api/215/15758#.E5.9C.B0.E5.9F.9F.E5.88.97.E8.A1.A8)。 |
| SecurityGroupId | 是 | String | 安全组实例ID，例如sg-33ocnj9n，可通过<a href="https://cloud.tencent.com/document/product/215/15808">DescribeSecurityGroups</a>获取。<br/>示例值：sg-4esrjvgl |
| GroupName | 否 | String | 安全组名称，可任意命名，但不得超过60个字符。未提供参数时，克隆后的安全组名称和SecurityGroupId对应的安全组名称相同。<br/>示例值：demo |
| GroupDescription | 否 | String | 安全组备注，最多100个字符。未提供参数时，克隆后的安全组备注和SecurityGroupId对应的安全组备注相同。<br/>示例值：demo |
| ProjectId | 否 | String | 项目ID，默认0。可在<a href="https://console.cloud.tencent.com/project">qcloud控制台项目管理页面</a>查询到。<br/>示例值：0 |
| RemoteRegion | 否 | String | 源Region,跨地域克隆安全组时，需要传入源安全组所属地域信息，例如：克隆广州的安全组到上海，则这里需要传入广州安全的地域信息：ap-guangzhou。<br/>示例值：ap-guangzhou |
| Tags.N | 否 | Array of [Tag](/document/api/215/15824#Tag) | 指定绑定的标签列表，例如：[{"Key": "city", "Value": "shanghai"}]。<br/>若指定Tags入参且指定IsCloneTags为true，会合并源安全组的标签和新增的标签。<br/>示例值：[{"Key": "city", "Value": "shanghai"}] |
| IsCloneTags | 否 | Boolean | 是否克隆标签。<br/>示例值：true |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| SecurityGroup | [SecurityGroup](/document/api/215/15824#SecurityGroup) | 安全组对象。<br/>示例值：{"SecurityGroupId": "sg-4esrjvgl", "TagSet": [], "SecurityGroupName": "demo", "SecurityGroupDesc": "demo", "ProjectId": "0", "CreatedTime": "2020-06-08 14:09:58", "UpdateTime": "2020-06-08 14:09:58", "Region": "ap-guangzhou"}|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|
