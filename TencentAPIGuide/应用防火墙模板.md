## 1. 接口描述

接口请求域名： lighthouse.tencentcloudapi.com 。

本接口 (ApplyFirewallTemplate) 用于应用防火墙模板到多个实例。

默认接口请求频率限制：20次/秒。

## 2. 输入参数

以下请求参数列表仅列出了接口请求参数和部分公共参数，完整公共参数列表见 [公共请求参数](/document/api/1207/47564)。

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Action | 是 | String | [公共参数](/document/api/1207/47564)，本接口取值：ApplyFirewallTemplate。 |
| Version | 是 | String | [公共参数](/document/api/1207/47564)，本接口取值：2020-03-24。 |
| Region | 否 | String | [公共参数](/document/api/1207/47564)，本接口不需要传递此参数。 |
| TemplateId | 是 | String | 防火墙模板ID。可通过[DescribeFirewallTemplates](https://cloud.tencent.com/document/product/1207/96874)接口返回值字段TemplateSet获取。<br/>示例值：lhft-s2dxd7iy |
| ApplyInstances.N | 是 | Array of [InstanceIdentifier](/document/api/1207/47576#InstanceIdentifier) | 应用防火墙模板的实例列表。列表长度最大值是100。 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| TaskId | String | 任务ID。<br/>示例值：lgtk-6brh0ciy|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 应用防火墙模板

应用防火墙模板

#### 输入示例

```
POST / HTTP/1.1
Host: lighthouse.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ApplyFirewallTemplate
<公共请求参数>

{
    "TemplateId": "lhft-s2dxd7iy",
    "ApplyInstances": [
        {
            "InstanceId": "lhins-wld7xie9",
            "Region": "ap-guangzhou"
        }
    ]
}
```

#### 输出示例

```json
{
    "Response": {
        "RequestId": "a880f7ad-a9a0-40a6-b67e-f3ad4f7d9abd",
        "TaskId": "lgtk-6brh0ciy"
    }
}
```

| 错误码 | 描述 |
|---------|---------|
| FailedOperation | 操作失败。 |
| InvalidParameterValue.Length | 参数取值长度不合法。 |
| ResourceNotFound.FirewallTemplateNotFound | 防火墙模板不存在。 |
| ResourceUnavailable.CannotApplyEmptyFirewallTemplate | 不能应用该防火墙模板。 |
| ResourceUnavailable.FirewallTemplateInUse | 防火墙模板在使用中，不支持该操作。 |
| UnauthorizedOperation.NoPermission | 无权限。 |
